# Graph app

Small Tkinter app for lab reports: type X and Y values, get a scatter plot with a linear regression line and its equation, then save it as PNG.

You can set the title, axis labels and colours. Each point is labelled with its coordinates.

- `graph_app_v1.py`: first version
- `graph_app_v2.py`: adds the input form and colour options

## Run it

```bash
pip install numpy matplotlib
python graph_app_v2.py
```
