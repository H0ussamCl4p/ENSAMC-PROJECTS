# Nova

Link page for Nova, a student list running for the ENSAM Casablanca students' association elections in 2024. It has a video background, the list's logo and links to its socials and action plan.

![Preview](previewnova.png)

Static HTML and CSS. Open `index.html` or see the [live page](https://h0ussamcl4p.github.io/ENSAMC-PROJECTS/web/nova/).

The action plan is in [document/](document).
