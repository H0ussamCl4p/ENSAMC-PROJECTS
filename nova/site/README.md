# Nova

Link page for Nova, a student list running in the 2024 ENSAM Casablanca students' association elections. It has a video background, the list's logo and links to its socials and action plan.

Static HTML and CSS. Open `index.html` or see the [live page](https://h0ussamcl4p.github.io/ENSAMC-PROJECTS/nova/site/).
