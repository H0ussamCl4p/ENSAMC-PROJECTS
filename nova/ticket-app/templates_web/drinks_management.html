How it Works

  1. Enable distribution when you're ready to start serving drinks
  2. Guests must be checked in (scanned at entrance) before they can claim drinks
  3. Use scripts/verify_drink.py script or API to scan tickets for drink claims
  4. Each ticket can only claim drinks once - no duplicates allowed
  5. Disable distribution when service ends

Terminal Scanner

Run this command to start the drink distribution scanner:

python scripts/verify_drink.py

This will start an interactive terminal where you can scan QR codes to claim drinks.
