🗑️ Bulk Delete Exclusive Tickets

This action permanently deletes all tickets of type exclusive. It cannot be undone. Consider using Bulk Cancel if you only want to void tickets instead of erasing them.

Danger Zone

  • All exclusive tickets will be removed from Firestore (or the CSV file if Firestore is disabled).
  • Statistics for exclusive tickets will reset.
  • Guests with exclusive tickets will disappear from the dashboard immediately.
  • This does not affect user/admin accounts.

To proceed, you must type the phrase exactly: DELETE EXCLUSIVE
