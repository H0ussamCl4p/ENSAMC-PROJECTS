Bulk Ticket Generation

Upload a CSV file to generate tickets for multiple guests

Upload Guest List

CSV columns supported: name OR (first_name,last_name), email. Optional: phone, school, cin, ticket_type, carrier.

Emails require GMAIL_ADDRESS and GMAIL_APP_PASSWORD env vars.

CSV Format Requirements

Required Columns:

  • EITHER name OR both first_name and last_name
  • email - Valid email address

The generator will prefer first_name+last_name when present.

The generator will prefer first_name+last_name when present.
For exclusive tickets, only first_name, last_name, and email are required.

Optional Columns:

  • phone - Guest phone number
  • school - Provenance
  • cin - National ID
  • ticket_type - Defaults to externe
  • phone - Guest phone number (not required for exclusive)
  • school - Provenance (not required for exclusive)
  • cin - National ID (not required for exclusive)
  • ticket_type - Defaults to externe. Use exclusive for exclusive tickets.

Ticket Types:

  • etudiant - Students (legacy alias accepted: ensamien)
  • adherent - Event adherents
  • externe - External guests (default)
  • organisateur-ade - Organizers (free access)
  • exclusive - Exclusive ticket (only first name, last name, and email shown)

Example CSV:

first_name,last_name,email,phone,school,cin,ticket_type
John,Doe,john@example.com,0612345678,ENSAM Casablanca,AB123456,etudiant
Jane,Smith,jane@example.com,0698765432,Université Hassan II,CD789012,externe
Ali,Benali,ali.benali@example.com,0670011223,ENSA Fès,EE998877,adherent
Sara,El Amrani,sara.elamrani@example.com,0655544332,EMI Rabat,,organisateur-ade
first_name,last_name,email,ticket_type
    John,Doe,john@example.com,exclusive
    Jane,Smith,jane@example.com,externe
    Ali,Benali,ali.benali@example.com,adherent
    Sara,El Amrani,sara.elamrani@example.com,organisateur-ade

Alternatively, you can use a single name column instead of first_name/last_name.

Note: Duplicate checking is enabled. Guests with matching name, email, or phone will be skipped.

Process: Tickets will be generated as PDFs and (optionally) sent via email automatically.
